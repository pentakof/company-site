# スカイライン・テクノロジーズ 企業サイト

クラウド・AI・業務システム開発を手がけるソフトウェア開発会社「スカイライン・テクノロジーズ」の企業サイトです。
HTML・CSS・JavaScript を 1 つの `index.html` にまとめた静的サイトで、ビルドやサーバーは必要ありません。

## サイトの構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー「テクノロジーで、ビジネスの地平線を広げる。」 |
| 私たちについて (`#about`) | 会社のビジョン・紹介 |
| サービス (`#services`) | 提供している 6 つのサービス |
| 数字で見る実績 | カウントアップ表示の実績数値 |
| 導入事例 (`#works`) | 導入事例の紹介 |
| 開発の流れ (`#flow`) | 開発プロセスのステップ |
| ニュース (`#news`) | お知らせ一覧 |
| 採用情報 (`#recruit`) | 採用案内 |
| お問い合わせ (`#contact`) | お問い合わせフォーム |

### 主な機能

- スクロールに応じたヘッダーの表示切り替え
- スマートフォン向けのハンバーガーメニュー
- スクロール時のフェードイン表示
- 実績数値のカウントアップ(OS の「視差効果を減らす」設定が有効な場合はアニメーションを省略)
- お問い合わせフォームの入力チェック

> **注意:** お問い合わせフォームはデモ用です。送信してもデータはどこにも送られず、完了メッセージが表示されるだけです。

## ブラウザで表示する手順

### 方法 1: ファイルを直接開く

1. エクスプローラー(Mac の場合は Finder)でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

ほかのブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへドラッグ&ドロップしてください。

### 方法 2: コマンドラインから開く

リポジトリのルートで次のコマンドを実行します。

```bash
# Windows (PowerShell / コマンドプロンプト)
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 方法 3: ローカルサーバーで開く(任意)

`http://localhost` で確認したい場合は、簡易サーバーを起動してください。

```bash
# Python がインストールされている場合
python -m http.server 8000

# Node.js がインストールされている場合
npx serve .
```

起動後、ブラウザで `http://localhost:8000`(`npx serve` の場合は表示された URL)を開きます。

## 補足

- フォント(Inter / Noto Sans JP)は Google Fonts から読み込むため、インターネットに接続していない環境では代わりのフォントで表示されます。
- 改行コードは `.gitattributes` で LF に統一しています。
